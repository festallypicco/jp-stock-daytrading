# jp-stock-daytrading

板情報ベースの日本株デイトレード自動売買システム

## ディレクトリ構成

| ディレクトリ | 役割 |
|---|---|
| `src/` | アプリケーション本体のソースコード |
| `tests/` | テストコード |
| `config/` | 設定ファイル |
| `docker/` | Docker 関連ファイル |
| `docs/` | 設計書・ロードマップなどのドキュメント |

## 開発ルール

- 新規テストファイルは必ず `tests/` 配下に作成すること
- ログ出力に絵文字・特殊 Unicode 文字を使用しないこと
